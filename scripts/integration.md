# 真机集成测试清单

## 前置记录

- Windows 10/11 x64 版本
- 微信主程序文件名、完整路径、文件版本
- 是否以管理员身份运行
- Windows Defender/第三方安全软件状态
- 使用 Process Explorer 只读记录对象类型和完整内核名称

## 用例

1. `--help` 显示用法与合规声明。
2. `--doctor` 输出权限、路径、版本、特征和句柄枚举状态。
3. `-n 2`、`-n 3`、`-n 4` 分别执行并确认窗口、登录状态和进程数量。
4. 已运行一个实例时追加启动，确认原实例持续收发消息。
5. 连续执行 100 次，记录成功率、启动耗时和是否产生僵尸进程。
6. 非管理员、错误路径、未知版本和安全软件拦截时确认中文提示。
7. 退出工具后微信继续正常收发消息、退出和再次启动。

4.x 若对象类型或名称未完成真机确认，不得把该版本标记为支持版本。
